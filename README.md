## Overview

The Virtual Reverse Vending Machine (VRVM) is a smart recycling system designed to encourage responsible plastic waste disposal. The system identifies recyclable plastic items, calculates reward points based on the disposed material, and allows users to redeem rewards. It also maintains user records and a leaderboard to promote environmental awareness and participation.

## Features

* User Registration and Login
* Plastic Item Detection and Classification
* Point Calculation Based on Recycled Items
* Reward Redemption System
* User Recycling History
* Leaderboard for Top Users
* MySQL Database Integration

## Technologies Used

* HTML
* CSS
* JavaScript
* JSP (Java Server Pages)
* MySQL
* Apache Tomcat
* TensorFlow.js (for object detection)


## Project Structure

* Frontend: HTML, CSS, JavaScript
* Backend: JSP
* Database: MySQL
* Server: Apache Tomcat
